## 실행

`C:\project\truckworks\frontend`에서 `npm run dev`를 실행하고 터미널에 표시된 주소를 연다. 이미 실행 중이면 열린 화면에서 변경 내용을 본다.

## 확인할 내용과 기대 결과

1. 브라우저 제목은 `TruckWorks · 생산 관제`이며 기본 다크 테마의 관제 화면이 표시된다. OS의 밝은 테마에서도 다크 화면이어야 한다.
2. 상단 현황, 좌측 생산 제어, 중앙 공장 배치 미리보기, 우측 상세·에이전트, 하단 이벤트 영역이 보인다.
3. 좌측 공정이나 중앙 설비를 클릭하면 양쪽 선택 강조와 우측 공정명·설명·처리시간이 함께 바뀐다. 순서대로 2·8·6·4·2초가 표시된다.
4. 생산·고장·복구·질문 조작은 비활성화되고 서버 연결 전 안내가 보인다. 생산 수치는 `—`로 표시되며 실제 생산이 실행되지 않는다.
5. Tab과 Enter로 공정 선택이 가능하고 키보드 포커스가 보인다.
6. 화면 폭을 줄이면 제어·장면·상세 순서로 패널이 세로 배치된다. 작은 화면에서 글자·패널이 겹치는지 직접 확인한다.

7. 개발자 도구의 계산된 글꼴 또는 Fonts에서 Pretendard가 실제 적용되는지 확인한다. CDN 요청이 성공해야 하며 네트워크 실패 시 시스템 글꼴로 대체된다.

원하면 `npm run lint`와 `npm run build`도 사용자가 직접 실행한다. 기대 결과는 오류 없이 종료되는 것이다. Codex는 테스트·빌드·린트·브라우저 검증을 실행하지 않았다.

## 현재 구현 범위

- 레이아웃, 공정 선택과 설정값 상세 표시, 연결 전 상태, 기본 반응형 배치.
- 중앙 설비와 프레임은 SVG로 표현한 정적인 배치도다. Three.js 기반 3D, 생산 엔진, 서버 상태, DB와 에이전트는 아직 연결하지 않았다.
- 세부 색상과 화면 배치는 초기 구현안이다. 사용자 화면 피드백에 따라 조정한다.
