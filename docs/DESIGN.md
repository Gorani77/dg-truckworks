# TruckWorks 디자인 기준

갱신일: 2026-10-12 (Asia/Seoul)

2026-10-12 A안 적용: 공장 환경 조작은 좌측 사이드바에서, 설비 관찰은 정보 전용 상세창에서, 원인 분석은 공통 AI 공장 분석에서 수행한다. 상단 선택 위치는 읽기 전용이다. 환경 조작 대상과 장면 선택은 독립적이며 안내 체험도 고장/복구를 직접 실행하지 않고 환경 메뉴로 안내한다. 현재 분석 데이터 범위는 실제 동작하는 차체 생산라인이다. 코드 작성 완료·사용자 확인 대기, FACTORY_ENVIRONMENT_UI.md 참고.

## 2026-10-12 현재 UI 표현 기준

사용자의 색감·화살표·문구 개선 요청을 반영했다. 아래는 작성된 구현 방향이며 사용자 시각 확인 완료를 뜻하지 않는다. 이전 날짜 항목은 변경 이력으로 보존한다.

- 표면은 중성 차콜의 단색이며 구분선·명도·간격으로 위계를 만든다. 생산 주요 조작만 절제된 황색으로 강조한다.
- AI 창 전체를 청록으로 채우지 않는다. 관련 설비 표시의 청록, 가동의 녹색, 고장의 적색은 의미를 전달하는 데 사용한다.
- 넓은 화면은 위치/생산 현황을 같은 상단 행에, 조작을 하단 바에 배치한다. 작은 화면은 기존 배치 분기를 유지한다.
- 장식 화살표, 반짝임 아이콘, 영문 장식 제목과 슬로건을 줄인다. 버튼에는 실행할 행동을, 안내에는 지금 필요한 정보를 쓴다.
- 분석 질문은 짧은 선택 항목, 답변은 구분선 아래 본문으로 표시한다. 실제 데이터와 전시/개발 예정 상태는 구분한다.
- 참고 출처와 사용자 확인은 UI_REFINEMENT.md에 기록한다.

## 현재 방향 — 공간 탐색형 시뮬레이션

사용자가 공장 탐색형 + 선택형 시나리오 체험 추천안의 개발을 승인했다. 포트폴리오 방문자가 처음부터 정보를 읽기보다 생산을 보고, 고장을 만들고, AI의 설명을 장면에서 이해하도록 구성한다. 기본 다크·Pretendard·절제된 황색은 유지한다.

- 화면 전체를 하나의3D 공장으로 사용한다. 카메라는 공장 전체→차체 라인→설비/부품으로 이동한다. 부품은 서버 수신 위치를 따라간다.
- 차체 라인은 실제 실행 구역이다. 소재 선반은 배경 모형, 조립 트럭은 확장 예정 전시 모형으로 구분한다. 실제 재고·생산량은 수신 자료로만 표시한다.
- 상단의 선택 위치/상태, 좌측 공장 환경 메뉴, 하단 생산/시점/AI 조작을 상시 표시한다. 환경 메뉴는 왼쪽, 상세·AI·기록·소개는 오른쪽 정보창으로 연다. 페이지 전체 스크롤 대신 정보창 내부 스크롤을 사용한다.
- 설비 이름은 전체 보기에서 최소화하고 선택/가리킴/고장 상태에 따라 노출한다. 긴 설명은3D 글자로 만들지 않고 읽을 수 있는 화면 위 정보창으로 제공한다.
- AI 관련 설비는 실제 답변의 설비 ID에 따라 강조한다. 고장 색과 구분하고 관측 시각·과거 상태 가능성을 표시한다. 사용하지 않은 도구나 영향 경로를 추정해 애니메이션으로 만들지 않는다.
- 안내 체험은 선택 사항이다. 생산·고장·분석·복구의 진행은 서버 상태와 실제 분석 응답에 연결한다. 설명을 읽었다는 이유로 사용자 이해/검증 완료를 기록하지 않는다.
- 키보드 탐색/부품 선택, Esc 복귀, 정보창 초점 이동, 작은 화면 배치, 감소된 모션, 2D 대체를 작성했다. 실제 동작·레이아웃 만족도는 사용자 확인 대기다.

구체 절차는 [IMMERSIVE_EXPERIENCE.md](IMMERSIVE_EXPERIENCE.md)를 따른다. 새3D 모형은 코드 도형이며 외부 자산/패키지를 추가하지 않았다.

## 2026-10-11 대표 설비 모델

사용자가 Blender 기반 대표 설비 제작안을 승인했다. ST-02를 정교한 산업용 디오라마 스타일로 제작하고 편집 원본/GLB를 생성했다. 도장 외장과 bevel, 가공 금속, 고무 지그, 측면 안전창, 제어판, 배선/가이드 구조를 구분한다. 정면은 생산 가시성을 위한 절개 구조이며 실제 장비의 안전 설계로 소개하지 않는다. 재고/생산품은 모델에 포함하지 않는다.

키 조명·윤곽 조명·로컬 생성 반사 환경과 공통 조명 색 토큰을 추가했다. 원격 HDR은 사용하지 않는다. 가동은 서버 진행률에 따른 고정→접근→가공→상승→해제이며 별도 생산 규칙이 아니다. 상태등은 수신된 상태에 연결한다. 대표 모델의 시각·가림·성능 확인은 대기이며 다른 공정의 모델 교체는 후속 범위다.

## 이전 방향 — 2026-10-07 관제 화면 결정 이력 (본문)

사용자 요청에 따라 기존 밝은 전시 모형 스타일에서 **다크 테마의 공장 관제 화면**으로 변경한다. 기본 서체는 Pretendard다. 실제 화면의 만족도와 동작은 사용자 확인 대기 상태다.

- 중앙 작업 영역에 가장 큰 면적을 배정하고 양쪽에 제어와 상세 정보를 둔다.
- 생산 현황은 동일한 둥근 카드 네 개 대신 하나의 상태 표시줄로 구성한다.
- 패널은 선과 면으로 구분하고 모서리와 그림자를 절제한다. 큰 홍보 문구와 장식용 영문 소제목은 사용하지 않는다.
- 배경은 차콜 계열, 텍스트는 명도 단계로 구분한다. 황색은 선택 상태와 핵심 강조에 사용한다. 향후 고장·경고·정상 색상은 상태 의미에 맞춰 별도 정의한다.
- 숫자는 Pretendard의 tabular-nums를 사용해 정렬한다. 글꼴·색상·간격은 공통 토큰으로 관리한다.
- 데이터가 없을 때 0이나 가짜 성능 수치 대신 연결 전, 수신 대기, `—`를 표시한다.
- 중앙은 기본 3D 장면과 2D SVG 전환을 작성한 상태다(2026-10-08, 사용자 설치·확인 대기). 설비의 소재·상태는 서버 응답으로 표시하고, 별도의 프레임 참고 모델은 생산품이 아님을 명시한다. 실제 전체 생산라인·가공 동작 완료로 표현하지 않는다.

## 서체와 색상 구현

- Pretendard v1.3.9 공식 배포 경로의 정적 CSS를 `frontend/index.html`에서 로드한다.
- CDN에 대한 네트워크 연결이 필요하다. 실패하면 Malgun Gothic·시스템 글꼴로 표시된다.
- 공통 토큰은 `frontend/src/styles/tokens.css`에 둔다. 기본 다크를 OS 색상 설정과 관계없이 적용한다.
- 구체적인 팔레트·화면 배치는 사용자 요청을 바탕으로 작성한 구현안이다. 사용자 화면 피드백에 따라 조정한다.

## 웹 자료에서 적용한 원칙

[VisiblePage의 디자인 가이드](https://visiblepage.com/insights/websites/make-ai-pages-look-less-generic/)는 획일적인 카드·색상·배치 대신 명확한 디자인 방향과 일관된 서체·팔레트·간격을 정하라고 제안한다. TruckWorks에서는 이를 산업 관제의 정보 위계, 연결 상태와 설정값의 구분, 작업 영역 중심 구성으로 해석해 적용했다. 특정 디자인이 AI처럼 보이는지는 주관적이며 화면 검증을 대신하는 근거로 사용하지 않는다.

서체 로딩 방식은 [Pretendard 공식 저장소](https://github.com/orioncactus/pretendard/blob/main/packages/pretendard/README.md)의 웹 배포 안내를 따른다.

## 2026-10-11 — 다섯 공정 모델의 스타일 통일

사용자가 ST-02의 시각 품질에 긍정적인 피드백을 주고 나머지 네 공정 확장을 승인했다. 소재 투입·구멍 가공·품질 검사·분리/적재도 같은 Blender 재질/모서리/구조 디테일로 제작하고 원본/GLB를 생성했다. ST-02는 기존 자산을 유지한다. 모든 상태는 기존 서버 자료로 표시하며 검사 모형은 실제 비전 AI가 아니다. 새 모델은 사용자 시각/가동 확인 대기이며 EQUIPMENT_ASSETS.md를 따른다.

## 2026-10-11 — 공장 공간과 생산품의 Blender 스타일

사용자가 공장 전체 모델화를 요청해 낮은 절개 벽/바닥/철골/배관/서비스 시설, 빈 선반/카트, 트럭 전시/작업대, 운반 롤러/받침, 차체 세 단계까지 확장했다. 차콜 바닥·진주색 도장·금속·고무와 절제된 황색 안전 표식을 기존 설비와 공유한다. 생산라인을 볼 수 있도록 벽은 낮게 두고 배관은 뒤쪽에 배치했다. 화면 코드 그리드 대신 바닥 이음새와 실제 구역 선을 모델링했다.

선택/진행률/AI 링은 동적 UI, 선반은 실재고와 무관한 배경, 트럭은 확장 예정 전시로 유지한다. 새 자산10종 생성 및 연결 코드 작성 완료, 실제 가림/밝기/재질/작은 화면/성능은 사용자 확인 대기다. FACTORY_WORLD_ASSETS.md 참고.

## 2026-10-11 — 공장 조작 화면 전체 UI

사용자가 모델링 개선 뒤 모든 UI 재디자인을 요청했다. 현재 UI는 블루 차콜 반투명 표면/가느다란 테두리/절제된 반경, 황색 생산 조작과 청록 AI, 공통 SVG 아이콘·Pretendard로 통일한다. 상단 상태/수량은 계기 형태, 하단 생산은 중심 조작부, 탐색/시점과 AI는 별도 기능 묶음으로 구분한다. 반복되는 동일 카드 대신 각 기능의 정보 위계를 사용한다.

설비 표지는 번호/이름/상태만 작게 표시하고 선택/가리킴에서 대기/예약/진행률을 확장한다. 상세창은 주요 수치→접힌 기술 정보, AI는 대상→질문→답변→근거, 기록은 필터/목록→선택 결과로 읽는다. 모든 수치는 서버 수신값/설정값에서 나온다. API가 제공하지 않는 분석 진행 단계를 만들지 않는다. 로딩/빈 상태/오류·2D·기존 보조 화면도 같은 기준을 사용한다.

UI_REDESIGN.md에 사용자 확인 절차를 기록했다. 현재 코드 작성 완료이며 실제 화면/반응형/접근성 검증 완료가 아니다.

## 2026-10-11 — 완성형 공장 탐색

공장 전체는9개 구역으로 확장했다. 상단 공장 지도/현재 위치 메뉴와 장면 표지로 접근한다. 모바일 전체 보기에서는 번호 표지를 사용하며 지도에서 이름과 상태를 읽는다. 차체 라인 외 구역은 정적 전시/기능 예정으로 표시하고 실행 조작을 연결하지 않는다. 운행과 운행 전 AI 예측은 미래 목표다. 상세 구성/사용자 확인은 FULL_FACTORY_MASTERPLAN.md 참고. 시각 검증 완료로 표시하지 않는다.
