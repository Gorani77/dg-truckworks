# 제품 구성과 차체 생산 공정 초안

작성일: 2026-10-07 (Asia/Seoul)
상태: 2026-10-07 사용자 승인으로 기본 제품 구성과 생산 규칙 확정. 세부 모델 치수·좌표는 제안이며, 기능 구현은 착수 전이다. 파일명은 기존 참조를 유지하기 위해 그대로 둔다.

2026-10-10 후속 구현: [설비 고장·복구](C:/project/truckworks/docs/STATION_FAULTS.md)와 잔여 가공 이어하기를 단독/1개/20개 흐름에 연결했다. 코드 작성 완료·사용자 확인 대기다. 이전 시점의 구현 전 메모는 이력으로 유지하며 강제 불량 조작은 여전히 보류다.

2026-10-10 현재 구현:1개 전체 공정·실행 제어에 이어20개 연속 생산·FIFO 입력 대기·이동 예약·출력 막힘/해제 코드 작성 완료, 사용자 확인 대기다. [연속 생산 안내](C:/project/truckworks/docs/BATCH_PRODUCTION.md)를 참고한다. 아래 최초 작성 시점의 설명과 현재 구현 상태를 구분한다. 고장/복구·강제 불량 조작은 아직 구현하지 않았다.

## 1. 확정된 전제

- 첫 공개는 차체 생산라인 + 읽기 전용 분석 에이전트다.
- 차체는 단순화한 프레임형이며 전체를 하나의 생산 부품으로 취급한다.
- 프레임 두 줄, 가로 연결부, 차축 결합 구멍, 운전석 장착 위치를 표현한다.
- 완제품 조립은 후속 단계다.

## 2. 제품 구성

모든 치수는 자체 설계한 모형의 가정이다. 실제 차량 규격이나 제조 도면이 아니다.

| 항목 | 제안 | 취급 |
|---|---|---|
| 제품 | 트레일러 연결을 고려한 3축 견인차 | 조립은 단계 6 |
| 차체 | 1개, 길이 180 × 폭 60 × 높이 12 mm | 첫 자체 생산 대상 |
| 차체 외형 | 긴 프레임 2줄 + 가로 연결부 3개 | 시각적 구조이며 별도 재고로 세지 않음 |
| 차축 | 3개: 앞 1개, 뒤 2개 | 후속 외부 공급 부품 |
| 바퀴 | 6개, 지름 30 mm | 차축당 2개, 뒷바퀴 복륜은 생략 |
| 운전석 | 1개, 길이 55 × 폭 70 × 높이 55 mm | 후속 외부 공급 부품 |

확정 범위: 3축 견인차, 차체 180 × 60 × 12 mm, 긴 프레임 2줄과 연결부 3개, 차축 3개, 바퀴 6개와 복륜 생략, 운전석 1개다. 바퀴 지름과 운전석 상세 치수는 모델 제작용 제안으로 남긴다.

차축 중심의 길이 방향 위치는 차체 앞끝에서 35, 125, 155 mm를 제안한다. 차체는 길이 방향으로 X, 높이 방향으로 Y, 폭 방향으로 Z를 사용하며 형상 중심을 모델 원점으로 삼는 안이다. 프레임 단면과 구멍 지름, 연결부·운전석 장착 좌표는 모델 제작 전에 구체화한다. 차축·바퀴와 함께 실제 맞물리는 세부 치수는 아직 정하지 않았다.

## 3. 생산 공정

기존 순서를 유지한다: 소재 투입 → 형상 가공 → 구멍 가공 → 검사 → 양품 적재 / 불량 분리.

공정 시간은 데모를 이해하기 위한 시뮬레이션 가정으로 확정했다. 기본 속도는 실제 1초당 시뮬레이션 1초를 제안한다.

| 공정 | 입력 → 출력 | 시간 | 화면 표현 |
|---|---|---|---|
| 소재 투입 | 소재 재고 → 투입된 소재 | 2초 | 두꺼운 직사각형 소재를 운반대에 놓음 |
| 형상 가공 | 소재 → 구멍 없는 프레임 | 8초 | 가공 헤드 동작 후 두 프레임과 연결부가 드러남 |
| 구멍 가공 | 프레임 → 검사 전 차체 | 6초 | 차축 결합 구멍과 운전석 장착부 표현 |
| 품질 검사 | 검사 전 차체 → 양품 / 불량 판정 차체 | 4초 | 스캔 표시와 판정 색상 |
| 분리·적재 | 판정 차체 → 양품 / 불량 보관 | 2초 | 판정 결과에 따라 경로 분기 |

공정 사이 이동은 2026-10-08 사용자가 구간당 1초로 확정했다. 5개 공정 처리 22초와 4구간 이동 4초를 합쳐 차체 1개는 26초다. 형상 가공 표현은 하나의 소재에서 프레임 형상으로 바뀌는 축소 모델이며 실제 트럭 프레임 제조 공법을 재현하지 않는다. 절삭 칩은 장식 표현으로만 다루고 별도 부품 재고에 포함하지 않는다. 부품 ID는 투입부터 보관까지 동일하게 유지한다.

## 4. 수량과 대기 규칙

- 기본 실행은 소재 20개를 가진 유한 생산 시나리오로 시작한다. 모두 처리하면 실행이 완료된다.
- 각 설비는 한 번에 차체 1개를 처리한다.
- 설비별 입력 대기 공간은 3개다. 작업 중·출력 대기 부품은 입력 대기 수량과 구분한다.
- 먼저 도착한 부품부터 처리한다.
- 다음 대기 공간에 빈자리를 확보한 뒤 이동을 시작한다. 이동 중 부품도 확보한 자리를 점유한다.
- 다음 공간이 가득 차면 완료 부품을 현재 설비에 유지하고 `BLOCKED`로 표시한다. 설비는 다음 작업을 시작하지 않는다.
- 양품과 불량 보관 공간은 각각 20개로 둬 기본 실행의 결과를 모두 담는다.
- 소재가 소진되면 새 투입을 멈추고 남은 부품 처리를 마친다.

## 5. 고장·불량·실행 제어

- 고장은 사용자가 설비를 선택해 발생시킨다. 초기에는 임의의 자동 고장을 넣지 않는다.
- 고장 시 작업 부품과 남은 처리시간을 유지한다. 수동 복구 후 남은 시간부터 이어간다.
- 고장 자체로 부품을 불량 처리하지 않는다. 작업 완료 후 출력이 막힌 상태에서도 고장·복구로 중복 완료되지 않게 한다.
- 기본 검사 불량 확률은 부품당 5%, 기본 난수 시드는 42로 제안한다. 실행 시작 시 부품별 검사 결과를 미리 결정하고 검사 완료 때 공개해 처리 순서의 영향을 줄인다. 검사에서는 이 결과를 읽으며 LLM이 판정하지 않는다.
- 20개 생산에서 불량품이 반드시 나오는 것은 아니다. 불량 분리 데모를 위해 선택한 부품을 불량으로 지정하는 별도 조작을 제안한다. 검사 시작 전까지 허용하고, 강제 지정 사실을 이벤트에 기록한다.
- 일시정지는 시뮬레이션 시계·가공·이동을 함께 멈춘다. 재개는 남은 시간부터 이어간다.
- 초기화는 새 실행 ID로 소재·설비·시드를 초기 상태로 되돌린다. 기존 실행 이벤트는 새 실행 상태에 적용하지 않는다.
- 고장과 복구, 대기 시작과 해제, 공정 시작과 완료, 검사 결과, 투입과 적재를 기록해 에이전트 설명의 근거로 사용한다.

## 6. 사용자 검토 및 다음 작업

3축·바퀴 6개 구성, 차체 크기, 공정별 처리시간(2·8·6·4·2초), 소재 20개, 설비 동시 처리 1개와 입력 대기 3개, 출력 막힘 시 대기, 고장 후 이어하기, 불량률 5%와 고정 시드, 일시정지·초기화 규칙을 사용자가 채택했다. 강제 불량 지정 조작은 선택 사항으로 보류하며 사용자 선택 전에는 구현하지 않는다.

세부 결합 치수와 공정 상태 전이를 구현 명세로 구체화할 때, 아직 제안인 세부 항목은 확정 사항과 구분한다. 시각 스타일과 상세 기술 구성 선택은 별도로 진행한다. 문서 작성만 수행했으며 테스트·빌드·실행 검증은 수행하지 않았다.
