## 체험 구성

페이지 전체가 하나의 공장 장면이다. 공장 전체에서 차체 생산라인·소재 보관·조립 전시 구역을 선택한다. 차체 라인에서는 설비 선택과 부품 따라가기로 이동한다. 소재 보관 선반은 재고를 시각적으로 집계하는 기능이 아니며 실제 잔량은 정보창에 따로 표시한다. 조립 구역은 확장 예정 전시 모형으로 실제 생산을 시작할 수 없다.

하단 생산 시작은 기본 20개 연속 생산이다. 1개 생산과 초기화는 생산 설정에서 선택한다. 설정의 초기화는 현재 실행을 바꾸는 기존 명령이며 단순 카메라 초기화와 구분한다. 카메라만 움직이거나 정보창을 여닫아도 생산은 계속 진행한다.

설비 선택은 상세 정보창과 고장/복구를 연다. 부품 선택은 서버 수신 위치를 따라간다. 드래그/휠로 수동 시점을 조작한 뒤 시점 초기화로 추적을 다시 시작할 수 있다. 키보드는 상단 탐색과 생산 설정의 차체 선택을 사용한다. Esc는 먼저 정보창을 닫고, 열려 있는 정보창이 없으면 공장 전체로 돌아간다.

AI에게 질문 창은 선택 설비 맥락을 전달한다. 실제 답변의 related_station_ids만 장면에서 강조하며 관련 설비 버튼을 누르면 그 설비로 카메라가 이동한다. AI 분석 시점과 현재 생산 상태는 다를 수 있다. 강조는 원인 판정 자체가 아니라 답변에서 참조한 설비 표시다. 실제 인용 이벤트와 사용 도구는 펼쳐서 읽는다. 진행 중에는 응답 대기만 표시하며 서버에서 제공하지 않는 세부 조회 단계를 꾸미지 않는다.

AI 창을 닫아도 같은 실행의 분석 요청·답변은 유지한다. 실행 초기화 또는 실시간 연결 끊김으로 현재 상태가 사라지면 실행에 묶인 화면·분석 요청을 정리한다. 브라우저 요청 취소가 이미 시작된 공급자 호출이나 비용 취소를 뜻하지는 않는다.

## 사용자가 수행할 확인

기존 로컬 실행 방법은 루트 README와 backend/README를 따른다. 프론트엔드 의존성이 준비되어 있다면 추가 설치 없이 기존 Vite 실행 경로를 사용한다. 아래는 기대 결과이며 실행한 결과가 아니다.

1. **첫 화면:** 웹페이지를 아래로 스크롤하는 대시보드 대신 공장 전체가 나타나고 로그·상세·이력은 닫혀 있어야 한다. 연결 전 수치는 `—`이며 생산은 비활성이다.
2. **공간 탐색:** 차체 구역 표지판 또는 탐색 메뉴로 라인 진입 → 설비 클릭 → 부드러운 접근 → 전체 보기. 보관·조립 구역도 이동하되 조립은 전시/확장 예정 표시만 보여야 한다.
3. **자유 생산:** 하단 시작은20개, 생산 설정의1개 선택/시작은1개다. 일시정지/재개가 기존 서버 상태와 연결되어야 한다. 생산이 끝나면 설정에서 초기화 후 재시작한다.
4. **부품 추적:** 움직이는 차체 클릭 또는 생산 설정의 차체 선택으로 카메라가 따라가야 한다. 부품이 가공·이동·적재할 때 상세와 위치가 수신 자료에 따라 변해야 한다. 수동 시점 조작과 시점 초기화도 사용한다.
5. **안내 체험:** 초기 상태에서 안내 체험 시작 →20개 생산 → ST-02 처리 중 고장 발생 → 앞뒤 흐름 관찰 → AI 창에서 직접 분석 요청 → 결과/관련 설비/근거 확인 → 복구. 정지 중 복구했다면 재개해야 한다. 안내 종료는 생산을 멈추지 않는다. 안내를 시작하기 전에 이미 생산 중이면 자동 초기화하지 않는다.
6. **AI 실패/성공:** 사용자가 원할 때 실제 요청한다. 키 미설정/서버 오류는 안내가 나타나고 다시 요청할 수 있어야 한다. 실패만으로 분석 단계를 완료하지 않아야 한다. 성공 시 응답의 관련 설비만 강조되고 관측 시각과 이벤트 근거를 볼 수 있어야 한다. 새 분석을 요청하면 이전 답변 강조는 사라진다.
7. **분석 수명:** AI 창 닫기/다시 열기에서 질문·답변이 유지되어야 한다. 답변의 설비 이동은 분석창을 유지해야 한다. 생산 초기화 후 이전 답변·강조·체험 단계가 새 실행에 남지 않아야 한다.
8. **기록:** 상단 기록 → 현재 이벤트/생산 이력/분석 이력. 기존 조회·필터와 DB 미설정/실패 안내가 사용 가능해야 한다. 과거 기록 선택은 현재 생산·카메라 상태를 덮지 않아야 한다.
9. **키보드·작은 화면:** Tab으로 탐색·조작·정보창 닫기에 접근한다. 정보창이 열리면 제목으로, 닫히면 이전 조작 요소로 초점이 돌아가야 한다. 좁은 화면에서 정보창 내부 스크롤과 하단 조작을 사용한다. OS 감소된 모션 설정에서는 카메라 전환이 즉시 적용되어야 한다.
10. **2D·연결 복구:** 2D 전환 후에도 선택·생산 제어가 가능해야 한다. 3D 실패 시 대체 배치도와 안내가 나타나야 한다. 서버 연결 끊김에는 현재 수치를 비우고 명령을 비활성화하며 복구 후 서버 상태를 다시 받아야 한다.

원하면 `C:\project\truckworks\frontend`에서 `npm run build`, `npm run lint`를 직접 실행한다. 빌드는 TypeScript/번들 오류가 없어야 하며 린트 결과도 직접 확인한다. Codex는 이 명령들을 실행하지 않았다.
